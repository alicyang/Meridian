# Meridian

**Meridian** is a browser extension that helps users navigate websites more easily, highlighting important content and providing context-aware guidance for complex pages.

---

## Features

- Highlights key sections of web pages
- Provides step-by-step guidance for tasks
- Explains menus and links for better understanding
- Works across multiple websites without losing context

---

## Installation (for developers / testers)

1. Download the latest `dist` zip from this repository.
2. Open **Google Chrome**.
3. Go to `chrome://extensions/`.
4. Enable **Developer mode** (toggle in the top-right corner).
5. Click **Load unpacked** and select the contents of the `dist` folder.
6. The Meridian extension should now appear in your Chrome toolbar.

---

## Usage

1. Navigate to any website.
2. Click the Meridian extension icon to interact with AI-powered chat and make queries about the page content. Follow step-by-step instructions for multi-step tasks.
3. Use the hovering search widget to search for anything on the page semantically. 
4. Highlight text and right-click to select trigger Meridian's in-line explain in context tooltip.
5. Open any pdf to view in Meridian's PDF viewer. The explain in context tooltip should also be available here.
